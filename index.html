질문 기반 탐구

학생 활동 순서

  1. 예측: 무역풍이 강해지면 동태평양의 수온 약층과 수온은 어떻게 될까?
  2. 조작: 오른쪽에서 느리게, 빠르게 부채질하며 변인을 비교한다.
  3. 반대 실험: 왼쪽에서 부채질해 서풍 편차를 만들고 강수 중심의 이동을 관찰한다.
  4. 설명: “바람 → 해수 이동 → 수온 약층 → 용승·수온 → 기압·강수” 순서로 근거를 연결한다.
핵심 발문

“수온이 먼저 변해서 바람이 바뀐 것일까, 바람이 먼저 바뀌어 수온이 변한 것일까? 실제 ENSO에서는 두 과정이 어떻게 서로를 강화할까?”

이 모형에서 단순화한 점과 수업 시 주의할 점

이 웹앱은 학생이 원인–결과의 방향을 빠르게 확인하도록 무역풍을 독립 변인처럼 조작합니다. 실제 ENSO는 해양과 대기가 서로 영향을 주는 결합 시스템이며, 적도 켈빈파·로스비파, 계절성, 해양 열함량, 대기 변동 등이 함께 작용합니다.

또한 ‘손을 왼쪽에서 흔들면 곧바로 엘니뇨가 발생한다’는 뜻이 아닙니다. 화면의 변화는 서풍 편차 또는 무역풍 강화가 일정 시간 지속될 때 나타나는 대표적 반응을 압축한 개념 모형입니다.

카메라 영상과 손 좌표는 외부 서버에 저장하거나 전송하지 않습니다. MediaPipe 모델 파일과 실행 라이브러리는 앱 시작 시 네트워크에서 불러옵니다.
